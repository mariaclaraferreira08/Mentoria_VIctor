# Lógica de Programação e Algoritmos

Esta trilha tem como objetivo aprender a pensar como um programador, organizar instruções e resolver problemas passo a passo antes de começar a escrever código em uma linguagem específica.

## 🎯 Objetivos

- Entender o que é lógica de programação.
- Aprender a criar algoritmos.
- Organizar instruções em uma sequência lógica.
- Compreender entrada, processamento e saída.
- Aprender a representar soluções usando pseudocódigo.
- Preparar a base para aprender Python e outras linguagens.

## 🎥 Material de estudo

**Curso de Algoritmos — Gustavo Guanabara**

[Curso em Vídeo](https://www.cursoemvideo.com/curso/curso-de-algoritmo/)

Procure pelo curso de Algoritmos e siga as aulas em ordem.

## 📚 Roteiro de estudos

### 1. Introdução
- [ ] O que é lógica de programação?
- [ ] O que é um algoritmo?
- [ ] Como organizar uma sequência de instruções?

### 2. Construindo algoritmos
- [ ] Entrada, processamento e saída.
- [ ] Variáveis e constantes.
- [ ] Operadores matemáticos.
- [ ] Expressões e comparações.

### 3. Controlando o fluxo
- [ ] Condições: se e senão.
- [ ] Estruturas de repetição.
- [ ] Resolução de problemas com algoritmos.

### 4. Prática
- [ ] Descrever os passos para calcular uma média.
- [ ] Criar um algoritmo para verificar aprovação.
- [ ] Criar um algoritmo para comparar dois números.
- [ ] Resolver desafios de lógica.

## ✏️ Como estudar

1. Assistir à videoaula.
2. Anotar os conceitos principais.
3. Resolver os exercícios sem copiar a resposta.
4. Explicar como chegou à solução.
5. Registrar as dúvidas para revisar comigo

## 📌 Progresso

Marque os tópicos conforme conseguir explicá-los e resolver exercícios sozinho.

Não é precisa ter pressa. A ideia é entender o que está fazendo, não apenas fazer o código funcionar.
