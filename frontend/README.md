# Front-end
O estudo será dividido entre os fundamentos e os conteúdos atuais da matéria.

## 🎯 Objetivos

- Aprender HTML, CSS e JavaScript.
- Entender como funcionam Vue e Vite.
- Acompanhar as aulas de Localbase.
- Conhecer Bootstrap.
- Praticar com pequenos projetos.

## 📚 Roteiro de estudos

### 1. HTML — Estrutura das páginas
- [ ] Entender o que é HTML.
- [ ] Criar a primeira página.
- [ ] Usar títulos, parágrafos, links e imagens.
- [ ] Criar listas e formulários.

### 2. CSS — Aparência das páginas
- [ ] Entender o que é CSS.
- [ ] Alterar cores, fontes e tamanhos.
- [ ] Trabalhar com margens e espaçamentos.
- [ ] Organizar elementos na página.

### 3. JavaScript — Lógica e interatividade
- [ ] Conhecer variáveis e tipos de dados.
- [ ] Usar operadores e condições.
- [ ] Aprender funções.
- [ ] Conhecer arrays e objetos.
- [ ] Trabalhar com eventos e elementos da página.

### 4. Vue e Vite — Projeto atual da faculdade
- [ ] Entender para que serve o Vue.
- [ ] Entender para que serve o Vite.
- [ ] Executar o projeto fornecido na aula.
- [ ] Conhecer componentes e interpolação.
- [ ] Entender como os dados são exibidos na tela.

### 5. Bootstrap — Estilização
- [ ] Entender para que serve o Bootstrap.
- [ ] Conhecer classes de estilo.
- [ ] Usar botões e formulários.
- [ ] Criar layouts responsivos.

### 6. Localbase — Armazenamento de dados
- [ ] Entender a finalidade do Localbase.
- [ ] Conhecer a estrutura básica do código usado nas aulas.
- [ ] Aprender a adicionar dados.
- [ ] Aprender a consultar dados.
- [ ] Aprender a atualizar e excluir dados.
- [ ] Praticar com os exemplos da faculdade.

## 🎥 Materiais de estudo

- [Curso em Vídeo](https://www.cursoemvideo.com/) — procurar cursos introdutórios de HTML, CSS e JavaScript.
- [Documentação do Vue](https://vuejs.org/guide/introduction.html).
- [Documentação do Vite](https://vite.dev/guide/).
- [Documentação do Bootstrap](https://getbootstrap.com/docs/).
- Priorizar os slides, exemplos e exercícios fornecidos pelo professor para Localbase.

## ✏️ Como estudar

1. Assistir a uma aula curta.
2. Anotar o que entendeu com as próprias palavras.
3. Reproduzir o exemplo no computador.
4. Fazer pequenas alterações para entender o código.
5. Registrar as dúvidas para revisar com a mentora.

## 📌 Progresso

Marque cada tópico quando conseguir explicar o conceito e realizar uma atividade prática.

**Importante:** não precisa aprender tudo de uma vez. Vamos por etapas e acompanhar também as atividades e os prazos da faculdade.
