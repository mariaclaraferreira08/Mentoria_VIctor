# Python

Python será estudado depois da introdução à lógica e aos algoritmos. Depois de criarmos essa base de python vamos para Programação Orientada a Objetos (POO), também com python

## 🎯 Objetivos

- Conhecer a linguagem Python.
- Aprender a escrever pequenos programas.
- Praticar variáveis, condições, repetições e funções.
- Resolver problemas usando programação.

## 📚 Roteiro de estudos

### 1. Primeiros passos
- [ ] Entender o que é Python.
- [ ] Instalar o Python e preparar o editor.
- [ ] Criar o primeiro programa.

### 2. Conceitos básicos
- [ ] Variáveis e tipos de dados.
- [ ] Entrada e saída de dados.
- [ ] Operadores matemáticos.
- [ ] Comparações e operadores lógicos.

### 3. Estruturas de controle
- [ ] Condições com `if`, `elif` e `else`.
- [ ] Repetições com `while` e `for`.
- [ ] Listas.

### 4. Funções e prática
- [ ] Criar funções.
- [ ] Resolver exercícios de lógica.
- [ ] Criar uma calculadora simples.
- [ ] Calcular a média de notas.
- [ ] Verificar se um aluno foi aprovado.

## 🎥 Material de estudo

[Curso de Python 3 — Mundo 1, Gustavo Guanabara](https://www.cursoemvideo.com/curso/python-3-mundo-1/)

## ✏️ Como estudar

1. Assistir à videoaula.
2. Escrever os exemplos no computador.
3. Modificar o código para testar o que aprendeu.
4. Resolver os exercícios sem copiar a resposta.
5. Anotar as dúvidas.

## 📌 Progresso

Marque cada tópico quando conseguir explicar o conceito e resolver exercícios sozinho.
