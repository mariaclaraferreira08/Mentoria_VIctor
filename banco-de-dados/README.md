# Banco de Dados

Esta trilha ajuda a entender como os dados são organizados e como consultar informações usando SQL. Os estudos acompanharão os conteúdos da faculdade.

## 🎯 Objetivos

- Entender o que é um banco de dados.
- Aprender a organizar informações em tabelas.
- Conhecer os relacionamentos entre tabelas.
- Aprender os comandos básicos de SQL.
- Praticar consultas e exercícios.

## 📚 Roteiro de estudos

### 1. Conceitos básicos
- [ ] O que é um banco de dados?
- [ ] O que é um SGBD?
- [ ] Tabelas, colunas e registros.

### 2. Organização dos dados
- [ ] Chave primária (`PRIMARY KEY`).
- [ ] Chave estrangeira (`FOREIGN KEY`).
- [ ] Relacionamentos entre tabelas.
- [ ] Modelo entidade-relacionamento (DER).

### 3. Introdução ao SQL
- [ ] O que é SQL?
- [ ] Consultar dados com `SELECT`.
- [ ] Filtrar dados com `WHERE`.
- [ ] Ordenar resultados com `ORDER BY`.
- [ ] Inserir dados com `INSERT`.
- [ ] Atualizar dados com `UPDATE`.
- [ ] Excluir dados com `DELETE`.

### 4. Prática
- [ ] Criar uma tabela simples.
- [ ] Fazer consultas em uma tabela.
- [ ] Filtrar e ordenar resultados.
- [ ] Praticar relacionamentos e consultas com `JOIN`.

## ✏️ Como estudar

1. Estudar um conceito por vez.
2. Anotar uma explicação com as próprias palavras.
3. Acompanhar os exemplos no computador.
4. Tentar resolver os exercícios sem copiar as respostas.
5. Anotar as dúvidas para revisar depois.

Marque cada tópico quando conseguir explicá-lo e realizar os exercícios correspondentes sem ajuda.
